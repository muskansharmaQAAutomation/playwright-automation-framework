# Playwright Automation Framework

End-to-end automation testing framework built using Playwright and TypeScript.

## Features
- Login Automation
- Add to Cart Flow
- Checkout Validation
- Cross-browser Testing
- Page Object Model (POM)

## Tech Stack
- Playwright
- TypeScript
- Node.js

## Installation

```bash
npm install
```

## Run Tests

```bash
npx playwright test
```

## Run Specific Test

```bash
npx playwright test loginTest.spec.ts
```

## Generate HTML Report

```bash
npx playwright show-report
```
